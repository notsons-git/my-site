# The Mentalist — fan dossier

Одностраничный фан-сайт по сериалу **The Mentalist**. Досье знакомит с завязкой истории, работой Патрика Джейна и его командой, не раскрывая личность Красного Джона и поздние сюжетные повороты.

## Что внутри

- Редакционный дизайн на бумажной палитре с графитовым текстом и красным акцентом.
- Адаптивная вёрстка для широких экранов, планшетов и телефонов.
- Краткое описание формата сериала и центральной сюжетной линии.
- Справка об основных участниках команды CBI.
- Интерактивный блок о методе Джейна: поведение, речь и контекст.
- Изображения берутся из папки `images/`; сторонние JS-библиотеки не используются.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны. Страница также подходит для GitHub Pages.
